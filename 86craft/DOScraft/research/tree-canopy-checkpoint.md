# Tree canopy experiment checkpoint

The first implementation is a work in progress, not a published release.
The shared ISO still contains the tested texture/chicken release documented
in `CHICKENS.md`.

The experiment stores sparse leaf-free surface exceptions and natural-tree
records alongside the existing far field. It draws compact crowns over the
log-height terrain band, while retaining the original panorama data. Planted
logs are marked separately so they do not acquire automatic crowns.

Pending: native storage/render/provenance checks, exact June 1990 DOS build,
8 MiB smoke, sustained walking comparison and performance measurements.
No conclusion about visual quality or speed has been reached.
