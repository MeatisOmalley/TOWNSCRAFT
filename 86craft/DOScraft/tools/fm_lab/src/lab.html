    How to use

    1. Press Start sound (or just play). Letter keys play notes when no text field has focus: Z–M and S D G H J for the lower octave, Q–P and the number row for the one above. - and = (or Page Down / Page Up) shift the octave, Space toggles sustain, Esc stops every note.
    2. Pick a game instrument, then shape it. The carrier is what you hear; the modulator changes its tone. Raise the modulator's total level number to make the tone purer, lower it for more bite. Feedback adds grit to the modulator.
    3. Every control changes the chip at once, on held notes too. Use Tab to move between controls and the arrow keys to adjust a slider.
    4. When it sounds right, press Copy Python row and replace that instrument's row in PATCHES in tools/build_music_pack.py, keeping the name. Then rebuild the music pack.
    5. To bring a patch back, paste its hex or row into the field under the hex line, or import an SBI file.

    Velocity works as in the game: it adds attenuation to the carrier's total level in 0.75 dB steps (channel volume 100, expression 127). Pitch uses the game's F-number table at the 49 716 Hz chip clock. Envelope times are approximate, for notes near middle C with KSR off.

    About

    The sound comes from Nuked OPL3 1.8 by Nuke.YKT (Alexey Khokholov), a cycle-accurate emulator of the Yamaha YMF262 built from die shots, compiled unmodified to WebAssembly and running in an AudioWorklet. Where a page refuses WebAssembly, the same build runs as JavaScript translated by Binaryen's wasm2js, with identical output. In OPL2 mode the YMF262 is register-compatible with the YM3812 that DOScraft targets; the chips differ mainly in their output DAC.
